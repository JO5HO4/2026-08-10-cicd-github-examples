# HSF Training CI/CD, GitHub Edition - Examples 

This repository contains the examples used in the HSF Training CI/CD with GitHub for [CompHEP 2026 @ BNL](https://indico.cern.ch/event/1672591/timetable/). 

Intended to be used in conjunction with the [lesson](https://michmx.github.io/2026-08-10-cicd-github/intro.html), 
it contains code and configuration files for the exercises.

## Original Lesson

The code in this repository is based on the original lesson ["Example analysis for the analysis preservation bootcamp"](https://github.com/hsf-training/hsf-training-cms-analysis)
by HSF Training.
